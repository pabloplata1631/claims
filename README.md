The original claims dashboard and SQL below are retained as a portfolio baseline.

public-data ingestion, SQL transformation layers, observed history, reporting,
and a planned Dev → UAT → Prod release process. See its README for implemented
work versus planned work; no production deployment or stakeholder approval is
claimed.
